Put each theme's image here.
The file name is the theme name, with the first letter of each word in uppercase.
Words are separated by hyphens, with no accents.

  Theme "Database"         ->  Database.jpg
  Theme "Web Development"  ->  Web-Development.png

Accepted formats: jpg, jpeg, png, webp, avif, svg.
If there is no image, the card uses a default blue gradient.
